<h2>게임 소개</h2>
1부터 100까지의 숫자 중 컴퓨터가 무작위로 선택한 숫자를 플레이어가 최대 5번의 기회 안에 맞추는 간단한 숫자 추측 게임입니다.<br>

<h2>게임 방법</h2>
1. 플레이어는 1부터 100 사이의 숫자를 입력합니다.<br>
2. 컴퓨터는 입력한 숫자가 정답보다 높은지, 낮은지 힌트를 줍니다.<br>
3. 5번의 기회 내에 숫자를 맞추면 승리합니다.<br>
4. 5번 안에 맞추지 못하면 게임에서 패배합니다.<br>

<h2>주요 기능</h2>
1. 무작위 숫자 생성 (1~100)<br>
2. 사용자 입력 받기<br>
3. 입력 값에 따른 힌트 제공 (더 높음/더 낮음)<br>
4. 남은 기회 카운트<br>
5. 승리 및 패배 메시지 출력<br>

<h2>실행 방법</h2>
1. 게임 파일을 실행합니다.<br>
2. 화면 안내에 따라 숫자를 입력합니다.<br>
3. 결과에 따라 다시 시도하거나 게임을 종료합니다.<br><br>
